# HCL NorthStar Assessment

AI-powered Sales & Policy Question Answering Agent for NorthStar Retail.

## Overview

This project implements a local question-answering agent that can answer:

- Sales analytics questions from the NorthStar sales dataset
- Customer support policy questions
- Shipping and delivery questions
- Return and refund policy questions
- Loyalty rewards questions
- Warranty questions
- Product sizing questions
- Seasonal promotion questions
- Stationery and bulk-order questions

The agent uses the provided sales dataset and NorthStar Retail policy documents to provide answers with the relevant source document.
